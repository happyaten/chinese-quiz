# 國文選擇題庫

國中、國小選擇題線上練習，手機和平板都能用，點選選項作答後會立即顯示對錯。

- **匯入測驗卷**：在首頁按「＋ 匯入測驗卷」，上傳 `.txt`、`.docx`（Word）或文字型 `.pdf`，或直接貼上題目文字，並選擇科目，就會自動整理成同樣的作答模式。
- 依序或隨機出題、每次 10／20／50 題或全部、錯題複習、成績與答錯題目列表、字體大小調整。
- 作答紀錄和匯入的題庫存在瀏覽器的 localStorage，只留在自己的裝置上。

## 可辨識的題目格式

每題用題號開頭，選項用 `(A)(B)(C)(D)` 或 `A. B. C. D.` 標示，答案可以寫在題號前面：

```
(B)1. 「子夜」相當於什麼時間？
(A)晚上九點 (B)晚上十一點到凌晨一點 (C)凌晨三點 (D)早上五點
```

答案與解析也可以寫在選項後面：`解題關鍵：…… 答案：(C)`。

或把答案表放在最後：`答案：1.C 2.A 3.B`、`答案：1-5 CABDA`。
用「第一回」「第二單元」這類標題分段，會自動分成不同部分；題目前面的閱讀文章也會一起帶出來。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。開啟 GitHub Pages（Settings → Pages → Source 選 Deploy from a branch → `main` / `/ (root)`）後，就能用網址在手機上打開。

## 開發

- `tools/parser.js`：網頁內用來整理題目的程式（匯入功能也是用它）。
- `tools/parse.py`、`tools/build.py`、`tools/template.html`：產生內建題庫用的程式與頁面範本。
- `tools/build_split.py`：產生拆檔版（`split/index.html` 加 `split/banks/*.json`），頁面只內嵌題庫目錄，切換題庫時才讀取對應的資料檔，用來避開 Artifact 單頁 16MB 的上限。repo 的 `index.html` 仍是單檔版。
- `tools/phys.py`、`tools/math/`：理化與數學題庫的題目、解析與附圖。
- `tools/zh/`：國二二段國文練習卷的解析程式（題目卷＋解析卷）與圖表截圖，產生 `tools/zh2.json`。
- `tools/ph/`：二段理化練習卷的解析與附圖裁切程式，產生 `tools/ph2.json`。
- `tools/gifted/`：資優理化段考的題目、答案與附圖框（`d1.py`～`d3.py`），用 `mkgt.py` 產生 `tools/gt.json`。
- `tools/geo/`：二段地理練習卷的解析與附圖裁切程式，產生 `tools/geo2.json`。
- `tools/kingan/`：金安地理 A 卷的逐題資料（`j1.py`～`j3.py`）與附圖裁切，產生 `tools/ja.json`。
- `tools/his/`：二段歷史練習卷的解析程式，產生 `tools/his2.json`。
- `tools/en/`：二段英文練習卷的解析程式，`mken.py` 產生文法選擇題 `tools/en2.json`，`mkcard.py` 產生寫作題練習卡 `tools/en2c.json`（題目資料加上 `card`、`ans` 欄位就會用看答案模式）。
- `tools/civ/`：二段公民練習卷的解析與附圖裁切程式，產生 `tools/civ2.json`。
- `tools/mock109-2/`：109 會考模擬二模的逐題資料（`d/*.py` 為題目，`d/*a.py` 為答案與解析）與附圖裁切框，`mkm2.py <科目>` 產生 `tools/m2*.json`。
- `tools/mock110-2/`、`tools/mock110-hl/`：110 會考模擬二模文揚版與翰林版的逐題資料與附圖框，`mkm3.py`／`mkm4.py <科目>` 分別產生 `tools/m3*.json`、`tools/m4*.json`。
- `tools/mock111-kh/`：111 會考模擬二模康軒版的逐題資料與附圖框，`mkm5.py <科目>` 產生 `tools/m5*.json`。
- `tools/mock111-hl/`：111 會考模擬二模翰林版的逐題資料與附圖框，`mkm6.py <科目>` 產生 `tools/m6*.json`。
- `tools/mock112-wy/`：112 會考模擬二模文揚版的逐題資料與附圖框，`mkm7.py <科目>` 產生 `tools/m7*.json`。
- `tools/mock112-kh/`：112 會考模擬二模康軒版的逐題資料與附圖框，`mkm8.py <科目>` 產生 `tools/m8*.json`。
- `tools/mock113-hl/`：113 會考模擬二模翰林版的逐題資料與附圖框（原卷為掃描檔，逐頁人工輸入），`mkm9.py <科目>` 產生 `tools/m9*.json`。
- `tools/elem5/`：國小五上國語、數學、自然的逐題資料（`zh/`、`ma/`、`sci/` 的 `d.py`，`ch` 為選擇題、`tf` 為是非題、`cd` 為看答案卡），`mke5.py <資料夾> <輸出>` 產生 `tools/e5*.json`（需要原卷 200dpi 頁面圖檔才能裁附圖）。
- `tools/recomp.py`：把題庫 JSON 內嵌的附圖重新壓縮，讓整個頁面維持在 16MB 以下。
